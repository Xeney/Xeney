## Чем занимаюсь

- Разрабатываю микросервисы на Go и gRPC для платёжного ядра: инициирование платежей, статусы, webhooks.
- Обеспечиваю надёжность: Transactional Outbox, Saga, идемпотентность, retry/backoff, PCI DSS.
- Оптимизирую производительность: pprof, аллокации, пулы соединений, запросы к PostgreSQL/Redis; p99 320 → 90 мс.
- Строю observability: Prometheus, Grafana, OpenTelemetry, Jaeger, SLO/SLA, on-call.
- Работаю с данными: PostgreSQL 500+ млн строк, партиционирование, реплики, ClickHouse.
